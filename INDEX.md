This repository contains the published Apache-2.0 SDK source and user-facing
release material. Install the wheel, or install `./python` from a clone.
It is not the full development tree or the proprietary native implementation.

The public release does not include native CUDA wheels or the separate Swift
App. Mac results do not qualify CUDA PC or CUDA server.
